How to use it

  
    
    
  1. Pick an animation in the list at the top left. Every frame is in the strip under the canvas.
    2. 
    
  2. Paint with the tools on the left in Zero's 16 colours. Colour 0 is see-through, and right-click paints it. The preview on the right plays the animation as the game does.
    3. 
    
  3. Move part of a frame with Select: drag a box around it, then drag inside the box. What you move floats over the art under it until you drop it with Esc or another tool, so you can drag across other pixels without wiping them.
    4. 
    
  4. Save writes your frames into the decomp's sprites folder. Only the animation you changed is touched.
    5. 
    
  5. Build ROM: pick USA or Japan beside it, then click. When it finishes, Last build on the right shows where the ROM is. Open that file in an emulator.
    6. 
  

  
Limits

  
    
    
  • Each sheet holds 48 tiles. Tile space shows how full each one is as you paint. Past 48, Save turns off until you trim.
    • 
    
  • Art more than 127 pixels from Zero's feet can't be placed by the game.
    • 
    
  • Teleport, Gale Attack, the smash, the two rod charges, buster-air and unk_51 were packed tighter by Capcom than this editor packs, so redrawing them at full size runs out of tiles.
    • 
  

  
Undo and restart

  
    
    
  • Revert frame and Revert all drop changes you haven't saved.
    • 
    
  • To undo everything you've saved, run git checkout sprites/ in the decomp folder.
    • 
    
  • To start the editor again later, run tools/sprite_editor/start.sh. It opens this page by itself.
